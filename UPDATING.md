# Updating the Signs2Go Portal

Plain instructions for keeping this site current. For Bobby and any AI chat working on it.

## Basics
- **Live site:** https://unmxd.github.io/signs2go-portal/
- **Repo:** github.com/UNMXD/signs2go-portal (public, GitHub Pages)
- **Local source:** `~/workspace/signs2go-portal/` — this folder IS the site. `build.py` regenerates the HTML pages from one template; edit the content in build.py (or edit the HTML directly and mirror the change in build.py), then re-run it.
- **Publishing:** upload changed files to the repo through GitHub's web UI (saved github.com login, account UNMXD). Pages rebuilds in about a minute. Confirm the deploy finished.
- **This is the INTERNAL team portal.** The customer storefront is a different site/repo (`unmxd.github.io/signs2go/`) — never mix them.

## Rules
1. **S2G branding only:** true black, true white, S2G green `#ACE50E`. Logo: white-letter version on black, black version on light. NEVER Sign Depot orange/blue.
2. **A little slick, still simple:** sticky black top bar, cards with photos, soft shadows. Big type, plain words, one idea per card, steps not levels, no gamification.
3. **Pictures on everything.** Machines get photo cards on the page of the job that runs them. Real machine photos come from Bobby; until then use a marked placeholder/photo spot, never a fake machine photo.
4. **Two jobs only:** Manager and Printer Operator. No department tree.
5. **Pricing law:** prices come ONLY from Bobby and Dad Raul's sheets. Never invent a price, never change a price value. Minimums: 24x18 = 10 pc; 4x4 = 2 pc pairs only; 4x8 = 1 pc; 18x12 wholesale = multiples of 16. "As low as $1.99" is Dad's advertising copy, NOT a sellable price.
6. **Public site:** no passwords, no sensitive documents, no real customer details. Sensitive files live in private Drive folders, linked — not stored here.
7. **English only** unless Bobby says otherwise. Never touch domain/DNS (signsrightnow.com, signs2go.us) without Bobby's explicit approval.
8. **One publish at a time**, and announce changes in the Signs2Go Portal chat.
